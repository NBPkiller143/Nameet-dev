[ 03 ] How I work

Five steps from idea to working system.

No shortcuts. Every step has a clear output.

  1. Step 01Step 01

    Understand

    I start with the real problem: who it's for, what goes wrong today, and what 'working' looks like.

    Output A clear problem statement

  2. Step 02Step 02

    Plan

    I sketch the system — screens, data, hardware — before writing code.

    Output A simple blueprint

  3. Step 03Step 03

    Build

    Hand-written code in Python, Flask and JavaScript, wired to real hardware when needed.

    Output A working prototype

  4. Step 04Step 04

    Test

    I test it in real conditions, fix what breaks, and make it fast and reliable.

    Output A stable build

  5. Step 05Step 05

    Improve

    Feedback, new features and documentation, all tracked on GitHub.

    Output A project that keeps getting better
